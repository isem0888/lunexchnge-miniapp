# Yield Desk — Telegram Mini App

## Подключение к Telegram

Текущая версия — веб-интерфейс мини-приложения. Для запуска внутри Telegram он должен быть опубликован по публичному HTTPS-адресу. Открытие `index.html` с диска (`file://`) Telegram использовать не сможет.

1. В Telegram откройте `@BotFather` и создайте бота командой `/newbot`. Сохраните токен бота у себя; не вставляйте его в HTML-файл и не отправляйте в чат.
2. Опубликуйте содержимое папки `D:\Lun` на хостинге статических сайтов, который выдаст HTTPS-адрес. Главная страница должна открываться как `https://ваш-домен/`.
3. В `@BotFather` откройте настройки бота и задайте URL мини-приложения через настройку Menu Button (`/setmenubutton`) или Configure Mini App. Укажите HTTPS-адрес сайта.
4. Откройте чат с ботом в Telegram и нажмите кнопку меню, чтобы запустить приложение.

Telegram SDK уже подключен в `index.html`; приложение сообщает Telegram о готовности, разворачивает окно и подстраивает цвета под тему.

## Что сейчас реализовано

- Интерфейс калькулятора и Telegram Mini App SDK.
- Подстройка светлой и темной темы Telegram.
- Кнопки MetaMask и Trust Wallet для кошельков, встроенных в браузер.

Позиции сохраняются только в браузере. Реальных вкладов и смарт-контракта нет. Для подключения кошелька прямо из Telegram WebView потребуется интеграция WalletConnect и Project ID. Проверьте ставки перед публикацией.
